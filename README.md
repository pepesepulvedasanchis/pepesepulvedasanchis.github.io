# Pepe Sepúlveda — sitio personal

Sitio personal de Pepe Sepúlveda, construido con Jekyll y publicado mediante GitHub Pages.

El objetivo del sitio es reunir contenido, proyectos, experiencia profesional y recursos relacionados con transformación digital, inteligencia artificial, estrategia, innovación y liderazgo tecnológico.

---

## Estructura principal

```txt
.
├── _article/              # Artículos publicados
├── _data/                 # Contenido estructurado del sitio
├── _includes/             # Componentes reutilizables
├── _layouts/              # Plantillas principales
├── _sass/                 # Estilos SCSS
├── assets/                # Imágenes, JavaScript, CSS y recursos estáticos
├── pages/                 # Páginas estáticas
├── projects/              # Páginas de proyectos
├── _config.yml            # Configuración principal de Jekyll
└── README.md              # Documentación del repositorio
