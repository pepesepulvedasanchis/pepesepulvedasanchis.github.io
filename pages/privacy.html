Datos que pueden tratarse

Este sitio puede tratar los siguientes datos, dependiendo de cómo lo uses:

  • Datos de navegación: dirección IP, tipo de navegador, sistema operativo, páginas visitadas, fecha y hora de acceso, tiempo aproximado de navegación y datos técnicos similares.
  • Datos de contacto: nombre, correo electrónico y cualquier información que envíes voluntariamente al contactar por email o mediante formularios.
  • Datos de suscripción: dirección de correo electrónico y página de referencia si decides suscribirte a comunicaciones del sitio.
  • Preferencias locales: información guardada en el navegador, como preferencias de interfaz, estado de suscripción o preferencias técnicas necesarias para que ciertas funciones del sitio recuerden tu estado.

Finalidades

Los datos pueden usarse para:

  • Responder a mensajes o solicitudes enviadas por el usuario.
  • Enviar comunicaciones si el usuario se ha suscrito voluntariamente.
  • Analizar de forma agregada el uso del sitio y mejorar su contenido.
  • Mantener la seguridad, estabilidad y funcionamiento técnico del sitio.
  • Evitar abuso, spam o usos indebidos del sitio.

Base del tratamiento

El tratamiento de datos se basa, según el caso, en el consentimiento del usuario, en el interés legítimo de mantener y mejorar el sitio, o en la necesidad de responder a una solicitud iniciada por el propio usuario.

Servicios de terceros

Este sitio puede utilizar servicios de terceros para alojamiento, analítica, formularios o funcionalidades técnicas. Estos servicios pueden tratar datos técnicos o de uso conforme a sus propias políticas.

GitHub Pages

El sitio puede estar alojado mediante GitHub Pages. Como proveedor de alojamiento, GitHub puede procesar datos técnicos necesarios para servir las páginas, mantener la seguridad y operar la infraestructura.

Google Analytics

El sitio puede utilizar Google Analytics para obtener métricas de uso, como páginas visitadas, origen del tráfico, dispositivo, navegador y datos agregados de navegación.

Google Analytics no debe utilizarse para recopilar información personal enviada directamente por el usuario mediante formularios o correos electrónicos. Aun así, Google puede tratar información técnica relacionada con la navegación.

Google Forms u otros formularios

Si el sitio usa formularios externos para suscripciones o contacto, los datos introducidos pueden ser tratados por el proveedor del formulario. En ese caso, el usuario debe revisar también la política de privacidad del proveedor correspondiente.

Cookies y almacenamiento local

Este sitio puede utilizar cookies, tecnologías similares o almacenamiento local del navegador para recordar preferencias, mantener funcionalidades básicas, medir el uso del sitio o mejorar la experiencia de navegación.

Puedes configurar tu navegador para bloquear o eliminar cookies y datos almacenados localmente. Al hacerlo, algunas funciones del sitio podrían dejar de funcionar correctamente.

Conservación de datos

Los datos se conservarán durante el tiempo necesario para cumplir la finalidad para la que fueron recogidos, atender solicitudes, mantener registros técnicos razonables o cumplir obligaciones aplicables.

Los datos enviados voluntariamente por email o formulario podrán conservarse mientras exista una relación de comunicación o mientras sean necesarios para responder a la solicitud.

Comunicación de datos

No se venden datos personales a terceros.

Los datos podrán ser tratados por proveedores técnicos necesarios para operar el sitio, como servicios de alojamiento, analítica, formularios, correo electrónico o seguridad.
